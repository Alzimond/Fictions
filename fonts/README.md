# Bundled fonts

- **Inter Variable 4.1**, used at weight 900 (Black) for headlines. Source: https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1 . Author's project: https://rsms.me/inter/ . See `Inter-LICENSE.txt` for the SIL Open Font License.
- **ModeNine**, by Grudnuk Creations, copyright Andrew C. Bulhak (1998) and Graham H Freeman (2001). Downloaded from https://www.dafont.com/modenine.font . The author's original `modenine.nfo` is preserved as `ModeNine-LICENSE.txt`; it states that the font is freely distributable and requires inclusion of that notice.

Both files are unchanged distributions. Font styling is declared in `../readability.css`. Mode Nine has a limited character repertoire; unsupported characters use the browser's fallback fonts without changing the encoded article. The symbol banner uses the original system monospace font to preserve its proportions.
IBM Plex Sans 400/600 is used for body text. Local TTF files use the included IBMPlexSans-LICENSE.txt (SIL Open Font License). Source: https://github.com/IBM/plex
